# SimpleFirewall

Личный Android firewall: **интернет только у выбранных приложений**.

- Один переключатель, один список разрешений для Wi-Fi и мобильной сети.
- По умолчанию всё заблокировано, включая новые приложения.
- Три вкладки: Firewall, Приложения и Трафик.
- Полный список сетевых приложений по умолчанию, включая предустановленные. Поиск соблюдает выбранный фильтр.
- Поиск, иконки, системные приложения, сохранение списка и последней вкладки.
- Без root, внешнего сервера, рекламы, аналитики и подписки.
- Android 10 и новее. Интерфейс на русском.

[Скачать SimpleFirewall.apk](https://github.com/kozzzak11/SimpleFirewall/releases/latest/download/SimpleFirewall.apk)

После установки отметьте нужные приложения, включите firewall и разрешите VPN в системном окне Android. Это локальный VPN для блокировки; подключения к удалённому серверу нет.

## Как работает

`VpnService` устанавливает маршруты `0.0.0.0/0` и `::/0` в локальный TUN. Пакеты не пересылаются. Выбранные пакеты исключаются из TUN через `addDisallowedApplication`, поэтому используют обычное подключение. Название Android API относится к доступу **к VPN**, а не к интернету. Общий обход VPN через `allowBypass()` не включается. Смена сети не меняет правила.

Приложения с одним UID объединены: Android применяет VPN-политику к UID. В списке есть все установленные пакеты такого UID, даже если только один запросил INTERNET. Удалённые приложения исключаются из списка разрешений при получении системного события удаления. Дата первой установки также проверяется: переустановка не наследует старое разрешение, даже если firewall был выключен во время удаления. Обычное обновление сохраняет разрешение.

Служба работает в foreground с уведомлением и кнопкой отключения; автоматический перезапуск после обычного уничтожения процесса запрашивается через START_STICKY. Никакие пакеты и адреса не записываются. Опрос трафика и wakelock отсутствуют.

## Границы работы

- Занимает единственный VPN-слот Android; другой VPN отключит firewall.
- Фильтрует приложения текущего Android-профиля. Раздача интернета, другие профили и низкоуровневый системный трафик вне VPN не входят в область фильтрации.
- Работа зависит от живой VPN-службы. При её остановке Android восстанавливает обычную сеть. Это не fail-closed / lockdown firewall.
- Системный режим «Блокировать соединения без VPN» несовместим: выбранные приложения обходят TUN. С 1.3.0 поддерживается «Постоянная VPN» Android, а после перезагрузки или обновления firewall запускается сам, если был включён и VPN-разрешение сохранилось. Если другой VPN или система отключили защиту, приходит уведомление «Firewall OFF» с кнопкой включения; выбор пользователя не сбрасывается.
- Некоторые приложения используют общий системный сервис (например, Google Play services для push). Его разрешение влияет на все использующие его приложения; это ограничение системной модели UID.
- На реальном телефоне следует проверить выбранные приложения, заблокированный браузер, переключение Wi-Fi/мобильной сети и работу при погашенном экране. CI не заменяет проверку конкретной прошивки.

## Сборка и проверка

JDK 17, Android SDK 35, Gradle 8.11.1, Android Gradle Plugin 8.9.2. Без сторонних runtime-библиотек.

```sh
gradle assembleDebug lintDebug assembleDebugAndroidTest
```

GitHub Actions собирает APK, запускает lint и сетевой тест на эмуляторе Android 15. Запросы выполняет отдельное CI-приложение `probe` с обычным UID, без привилегий владельца VPN. Оно не включено в основной APK. Тест проверяет: отсутствие доступа у невыбранного UID, наличие обоих default routes IPv4/IPv6, запрет обхода привязкой к физической сети, выдачу доступа выбранному UID, отзыв доступа и восстановление сети после отключения. HTTP-сервер находится на хосте эмулятора; внешний интернет тесту не нужен. IPv6 проверяется по конфигурации маршрута, не сквозным IPv6-запросом.

Публикация APK происходит только после успешных проверок. Отчёты сохраняются в артефактах Actions.

С версии 1.3.0 релизный APK (не debuggable) подписан постоянным ключом из GitHub Actions Secrets и публикуется только по тегу версии `vX.Y.Z` после успешных проверок; существующие релизы не перезаписываются. CI сверяет SHA-256 сертификата, поэтому обновления ставятся поверх. Переход с 1.2.0 (временный debug-ключ) требует однократной переустановки.


## Трафик (1.2)

Скорость приёма/отправки устройства приблизительно оценивается по разнице публичных счётчиков TrafficStats раз в секунду. Это не измерение скорости конкретного приложения и не счёт оператора. Включает служебный обмен устройства; виртуальные интерфейсы могут влиять на оценку.

Расход за сегодня / 7 / 30 календарных дней берётся из NetworkStatsManager: Wi-Fi и мобильная сеть суммируются, приём/передача и UID не смешиваются. Начало периода — местная полночь телефона; 7/30 дней включают текущий день. Android собирает историю в временные корзины, может обновлять её с задержкой и приближённо относить трафик к границам периода. Общий UID отображается одной строкой, чтобы не удваивать данные. Если часть сетей недоступна, UI явно помечает неполные значения. Новых фоновых служб или второго VPN нет: опрос работает только на открытой вкладке, раз в секунду для скорости и раз в 15 секунд для истории.

Для чужих UID нужен системный Usage Access. Приложение открывает системный экран по кнопке; без разрешения firewall работает, расход по приложениям не подменяется нулями.

## Стабильность VPN (1.2)

Повторная команда с тем же списком больше не пересоздаёт интерфейс. Изменения списка объединяются с задержкой 250 мс. START/STOP/UPDATE разделены, чтобы очередь команд не теряла запрос на включение. Изменение физических сетей/DNS отслеживается пассивно; через 750 мс правила переприменяются с тем же списком. Текущий TUN удерживается до успешного открытия замены, без намеренного отключения защиты между ними. DNS-конфигурация берётся с физических сетей, а не с постоянного фиктивного сервера; офлайн используется блокирующий адрес-заглушка. Выбранные UID выходят напрямую через физическую сеть. Кнопка «Восстановить соединение» также переприменяет список без выключения firewall.

Это исправляет найденные проблемы управления VPN, но конкретный периодический сбой YouTube на пользовательском устройстве без его журналов не воспроизведён и полностью устранённым не объявляется.

Проверки 1.2 включают сравнение полного списка UID с установленными сетевыми приложениями, одинаковую работу фильтра с поиском, повторные изменения правил и восстановление, а также Usage Access и учёт реального локального HTTP-трафика отдельного UID.

## 1.3.0

- Новый дизайн всех вкладок: крупный переключатель-щит, карточки статистики, фильтры-чипы, иконки приложений и в «Трафике», полоски расхода.
- Единицы B / KB / MB / GB (десятичные, как в настройках Android), скорость в KB/s и MB/s.
- Постоянная VPN, автозапуск после перезагрузки/обновления, уведомление «Firewall OFF» при отключении другим VPN.
- VPN не пересоздаётся из-за смены IPv6-адресов, DNS или проверки сети; только при реальной смене физической сети (с задержкой 3 с) или изменении списка. VPN наследует «лимитность» физической сети (`setMetered(false)`).
- Подсказка про Google Play services: через них идут push почти всех приложений. Разрешение даётся только по нажатию.
- Убрано разрешение INTERNET: приложению сеть не нужна.
- Иконки кэшируются в памяти и грузятся в фоне.
