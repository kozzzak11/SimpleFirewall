# SimpleFirewall

Личный Android firewall: **интернет только у выбранных приложений**.

- Один переключатель, один список разрешений для Wi-Fi и мобильной сети.
- По умолчанию всё заблокировано, включая новые приложения.
- Поиск, иконки, системные приложения, сохранение списка.
- Без root, внешнего сервера, рекламы, аналитики и подписки.
- Android 10 и новее. Интерфейс на русском.

## APK

[Скачать SimpleFirewall.apk](https://github.com/kozzzak11/SimpleFirewall/releases/latest/download/SimpleFirewall.apk)

После установки отметьте нужные приложения, включите firewall и разрешите VPN в системном окне Android. Это локальный VPN для блокировки; подключения к удалённому серверу нет.

## Как работает

`VpnService` устанавливает маршруты `0.0.0.0/0` и `::/0` в локальный TUN. Пакеты не пересылаются. Выбранные пакеты исключаются из TUN через `addDisallowedApplication`, поэтому используют обычное подключение. Название Android API относится к доступу **к VPN**, а не к интернету. Общий обход VPN через `allowBypass()` не включается. Смена сети не меняет правила.

Приложения с одним UID объединены: Android применяет VPN-политику к UID. В списке есть все установленные пакеты такого UID, даже если только один запросил INTERNET. Удалённые приложения исключаются из списка разрешений при получении системного события удаления. Обычное обновление приложения сохраняет разрешение.

Служба работает в foreground с уведомлением и кнопкой отключения; автоматический перезапуск после обычного уничтожения процесса запрашивается через START_STICKY. Никакие пакеты и адреса не записываются. Опрос трафика и wakelock отсутствуют.

## Границы работы

- Занимает единственный VPN-слот Android; другой VPN отключит firewall.
- Фильтрует приложения текущего Android-профиля. Раздача интернета, другие профили и низкоуровневый системный трафик вне VPN не входят в область фильтрации.
- Работа зависит от живой VPN-службы. При её остановке Android восстанавливает обычную сеть. Это не fail-closed / lockdown firewall.
- Системный режим «Блокировать соединения без VPN» несовместим: выбранные приложения обходят TUN. Always-on VPN намеренно отключён в manifest. После перезагрузки включите приложение вручную.
- Некоторые приложения используют общий системный сервис (например, Google Play services для push). Его разрешение влияет на все использующие его приложения; это ограничение системной модели UID.
- На реальном телефоне следует проверить выбранные приложения, заблокированный браузер, переключение Wi-Fi/мобильной сети и работу при погашенном экране. CI не заменяет проверку конкретной прошивки.

## Сборка и проверка

JDK 17, Android SDK 35, Gradle 8.11.1, Android Gradle Plugin 8.9.2. Без сторонних runtime-библиотек.

```sh
gradle assembleDebug lintDebug assembleDebugAndroidTest
```

GitHub Actions собирает APK, запускает lint и сетевой тест на эмуляторе Android 15. Тест проверяет: отсутствие доступа у невыбранного UID, наличие обоих default routes IPv4/IPv6, запрет обхода привязкой к физической сети, выдачу доступа выбранному UID, отзыв доступа и восстановление сети после отключения. HTTP-сервер находится на хосте эмулятора; внешний интернет тесту не нужен. IPv6 проверяется по конфигурации маршрута, не сквозным IPv6-запросом.

Публикация APK происходит только после успешных проверок. Отчёты сохраняются в артефактах Actions.

Сборка подписывается стандартным debug-ключом, который создаётся только во временной среде GitHub Actions и не публикуется. Ключи в репозитории отсутствуют. Повторная сборка в новой среде получит другую подпись: для установки потребуется удалить предыдущую версию, что удалит настройки. Для стабильных обновлений в будущем нужен отдельный закрытый ключ через GitHub Actions Secrets.
